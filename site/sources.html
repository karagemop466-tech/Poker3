Official URLs are re-checked on a schedule by scripts/check_sources.py, which records the retrieval time, the HTTP status and a content hash for each one. A changed hash is a review signal, not proof that a tournament value changed: rotating page content can produce a false signal. The latest results are on the Change monitor page.
