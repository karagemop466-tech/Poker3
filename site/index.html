What the date in the last column means. It is rendered from site/checks.json at page load, so it can only ever show the date of the last automated re-check of that structure PDF by scripts/check_sources.py — the date that run actually recorded (the latest run and its outcome are printed on the source log). It is not the date the values were read: those are lastChecked 2026-11-19 and lastVerified 2026-11-19 in the tournament table, because the whole official schedule page and its 94 rows were read again by hand on 19 November 2026 and matched line by line. A hash match confirms the document is unchanged; it does not re-verify a number by eye. If a cell reports CHANGED, the venue re-published that PDF after the values were copied here, and a human must re-read it before any value is trusted — the monitor records the change, it never edits a row.

No 8 AM start or finish time appears on these sheets. Registration closing is not a finish time. A fallback replaces the primary unless the player is out and can arrive before registration closes. A bounty-inclusive guarantee is not a cash-only pool.
