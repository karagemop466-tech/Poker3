Change monitor

Official URLs are re-checked on a schedule by scripts/check_sources.py. For each URL it records the retrieval time, the HTTP status, a content hash and whether the page changed since the last check. A changed hash is a review signal, not proof that a tournament value changed: dynamic or rotating content produces false signals. Open the page and check the value by hand before changing anything.

How the monitor works

  • Only URLs tagged as official in the source register are checked. Third-party route estimates are excluded on purpose.
  • A first run records a baseline hash. Later runs compare against it.
  • An unreachable URL is recorded as unavailable. It is never counted as unchanged and never as verified.
  • The log is committed to the repository and the site is redeployed after each run.
