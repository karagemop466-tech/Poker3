How the totals are built

  • Room tax. Clark County Room Tax of 13.38%, published in The Venetian's official hotel terms and conditions: 'Daily rates do not include the applicable Clark County Room Tax of 13.38%.'
  • What the tax applies to. the nightly room rate and the resort fee (the resort fee line '$55 plus applicable tax' and the Caesars fee line '$62.30 ($54.95 plus $7.35 tax)' both show the fee taxed at the same 13.38%)
  • Method. True nightly cost in this dashboard is computed as (published nightly rate including the resort fee) x 1.1338. It is an arithmetic restatement of the published rate and the published tax rate, not a quote. The published booking pages state 'Excludes Taxes', so the final folio can differ.
  • Sample dates. No travel dates were supplied by the requester. This is a research sample window chosen because it sits inside the published Venetian DeepStack Extravaganza IV series (Nov 16 - Dec 23, 2026). Every calculator on this site can be pointed at other dates.

Check the current rate for your own dates

The rate table above is a dated log, not a live quote. To price the same stay for different dates, run the lookup tool against the property's own booking engine and append the result to the log:

python3 scripts/check_hotel_rates.py --hotel horseshoe \
    --arrival 2026-12-10 --departure 2026-12-14 --write

Known property ids: horseshoe, caesars-palace, paris, venetian, wynn, bellagio. Run it with --list for the full list and without --write to see the result without changing the log.

The tool never invents a rate. If the booking engine will not return a price for the requested dates, it records nothing and says why. Each observation it writes keeps the URL, the retrieval timestamp, the room type and the occupancy it was read for.
