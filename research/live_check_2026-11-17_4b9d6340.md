## Defects found and fixed by this session

1. **The tournament table's 30-minute walking limit was on by default and looked one way only**, which hid
   196 of 341 rows on first paint — including every Wynn, Caesars and Horseshoe row — because no route had
   been recorded from the Venetian *to* those venues, not because any of them is too far. The limit is now
   opt-in, is measured from a hotel the reader picks, resolves a pair through the reverse of a recorded row
   while labelling that it did so, and prints the number of rows it hides split between "over the limit" and
   "no measured route". Driven headlessly by `tests/walk_limit_render.js` and wired into CI.
2. **F32 stated "14 route rows" while 15 were published at the time** — a stale count of exactly the kind this
   file keeps recording. This session rewrote it with the census and the reverse-pair caveat, and C14 in
   `scripts/coverage.py` likewise. Both were then overtaken by a concurrent session that completed the matrix:
   see the merge section below for the reconciled text and the tests that now pin it.

   formula — but the Venetian calendar cells and the Caesars rate display already include the resort fee
   (both sentences confirmed above). `site/calculator.html` now says do not paste a calendar figure into the
   box and points at F69, which shows the two disagreeing on the same seven nights.
