## V5 — trip-window rows against the schedule PDF

The 19 rows for 23–30 November 2026 were copied verbatim from the live PDF into `raw/venetian_dse_nov_2026_schedule_pdf_trip_window_2026-11-19_arena-02417c60.md`. They were compared with the 19 published Venetian events in that window, using date, start time, buy-in and guarantee. The check is reproducible with the script below.

- **Agreement:** 18 of 19 rows match exactly. The comparison failed on the Day 2 restart row only.
- **Residual 1 (F63, recorded):** the restart row on 25 November at 11:00 AM is the printed Day 2 restart of Event 7. The PDF leaves its guarantee cell blank. The published row carries $75,000, which the site takes from that event's structure sheet. This is a sheet-sourced value, not a printed value on the restart row, and it is already flagged.
- **Residual 2 (F46, recorded):** the PDF's DATE cell for Events 17 and 18 (28 November) holds sponsor art, not a date. The rows match the date printed above them, and the published date agrees.

Reproduction (run from the repository root):

```python
import json, re, datetime
raw = open('raw/venetian_dse_nov_2026_schedule_pdf_trip_window_2026-11-19_arena-02417c60.md', encoding='utf-8').read()
rows, carry = [], None
for line in raw.splitlines():
    if not line.startswith('| ') or line.startswith(('| DATE', '| ---')):
        continue
    cells = [c.strip() for c in line.strip('|').split('|')]
    if len(cells) != 9:
        continue
    date_s, num, name, time, reg, guar, chips, level, coin = cells
    m = re.match(r'(\w+), (\w+) (\d+)', date_s)
    if m:
        carry = datetime.datetime.strptime(f"{m.group(2)} {m.group(3)} 2026", "%B %d %Y").date().isoformat()
    bi = int(re.search(r'\$([\d,]+)', name).group(1).replace(',', ''))
    rows.append((carry, time, bi, int(guar.strip('$').replace(',', '')) if guar else None))
d = json.load(open('site/data.json'))
pub = sorted((e['date'], e['time'], e.get('buyIn'), e.get('guarantee'))
             for e in d['events'] if e['venue'] == 'venetian' and '2026-11-23' <= e['date'] <= '2026-11-30')
print(sorted(rows) == pub, [k for k in pub if k not in sorted(rows)])
```

Expected output: `False [('2026-11-25', '11:00 AM', 400, 75000)]`. That is the single restart-row residual (F63). Every other row matches.
