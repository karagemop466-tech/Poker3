   `build_type: legacy`, `source: main /`. On 2026-11-19
   [/Poker3/calculator.html](https://karagemop466-tech.github.io/Poker3/calculator.html),
   [/Poker3/browse.html](https://karagemop466-tech.github.io/Poker3/browse.html),

   [/Poker3/sources.html](https://karagemop466-tech.github.io/Poker3/sources.html) each returned
   "404 File not found", while [/Poker3/site/calculator.html](https://karagemop466-tech.github.io/Poker3/site/calculator.html)
   rendered the real page. Root cause: two publishers writing the same host (flag F29); the legacy
   branch build serves the repository root, where those six files plus the four `venues/` detail pages
   did not exist. **Fix:** a root-level redirect stub for every canonical page (17 pages), so the path
   works under either publisher. Published on the
   [Flagged for review page](https://karagemop466-tech.github.io/Poker3/site/flagged.html#publishing-review).
   **Still needs a user decision:** switch Pages source to *GitHub Actions* in repository settings;
   `PUT /pages` returns 403 for the integration token.
2. **No written single-entry policy (F31).** Re-confirmed on sheets 6 and 30 today: one printed
   buy-in and no re-entry/rebuy/add-on clause, but no maximum-entries-per-player statement. The
   "single-entry / freezeout confirmed" filter therefore returns 0 rows, which is correct. Link:
   [sheet 6](https://www.venetianlasvegas.com/content/dam/vlvweb/casino/poker/deepstack/2026/structures/dse_nov_2026-structure_6.pdf).

   labelled estimates; no impossible sequence is presented as playable. Link:

   isolated in their own category. Link: [sheet 30](https://www.venetianlasvegas.com/content/dam/vlvweb/casino/poker/deepstack/2026/structures/dse_nov_2026-structure_30.pdf).
