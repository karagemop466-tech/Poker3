## 2. Defects found and fixed in this session

### D1 — `site/q-and-a.html`: all 19 official source URLs were invisible (fixed)

The Q&A worksheet added by PR #207 shipped with Markdown that HTML cannot render:

1. **Every source cell used a `<https://…>` autolink.** HTML parses that as an unknown
   element whose tag name is `https:` and whose "attributes" are the path segments, so
   the URL never reached the page. A parse of the shipped file showed
   `https: {'www.venetianlasvegas.com': '', 'legal': '', …}` — **19 source links,
   zero visible**. The brief requires a source link on every table row; the page had
   none a reader could see or click.
2. **The table was split in three pieces.** The column header sat in its own empty
   `<table>`; row 1 was promoted into a *second* table's `<thead>` as `<th>` cells; a
   Markdown `|---|---|---|---|---|` separator leaked between them as literal text.
3. **31 `**bold**` spans rendered literally**, and the five-item "unblock" list was
   split into two lists (1 + 4) by a stray `<p>`.

**Root cause:** the file was in no gate's page list — absent from `verify_site.py`'s
`PAGES`, from `canonical_smoke.py`'s page table, and from
`test_official_row_sources_97eba119.CANONICAL_PAGES`. Nothing read it.

**Fix:** rebuilt as one table (header + 22 rows, 110 `<td>`, 5 `<th>`); converted all
19 autolinks to real `<a href>` anchors and all 31 bold spans to `<strong>`; removed
the separator; remerged the list into one 5-item `<ol>`; and linked the 4 rows that
carried prose instead of a source (`sheets.html`, `schedule.html`, `flagged.html`,
`hotels.html`). **No statement or URL was altered** — only the markup around them.

### D2 — the gate did not cover `site/` as a whole (fixed)

`verify_site.py` checked a hand-maintained `PAGES` tuple, so a new page could ship
unchecked. Added:

- `q-and-a.html` to `PAGES` (19 pages) and to `canonical_smoke.py` (14 main pages) and
  to `CANONICAL_PAGES` (19, so the root-path guard covers it too);
- **`MARKDOWN_ARTIFACTS`**, scanned across **all of `site/**/*.html`** via `rglob`, so
  coverage no longer depends on the list. It fails on raw `<https://`, raw `**bold**`,
  `[label](url)` and `|---|`.

Verified by negative test: each of the four defect classes fails the gate, on a listed
page *and* on an unlisted one. New `tests/test_q_and_a_rendering.py` (7 tests, stdlib
only — CI installs PyYAML and nothing else) pins the repaired shape; it produces 6
failures when the original defects are reintroduced.

Flag **F106** says: *"The method is written down in two places: `site/tournaments.html`
says 'the estimate adds two more levels', and **flag F37** says 'the day plan estimates
a finish from the late-registration cut-off plus two levels'."*

- **F37 does not contain that sentence.** F37 is *"Caesars Palace and Horseshoe resort
  fees are now confirmed; their room-tax percentage is not."* The quoted sentence lives
