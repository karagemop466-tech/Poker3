Suggestions for improving this site (for review, not implemented)

These are proposals. None has been built, and none will be built until you approve it.

  1. Date filter. Add a date selector that shows only events on the chosen days.
  2. Structured rule fields. Store single-entry, re-entry, add-on, and fee values separately for each event, each with its source excerpt and retrieval date.
  3. Schedule overlap check. Once finish times are verified, flag any two events that cannot be played in sequence.
  4. Walking-route check. Add official-address walking times for each hotel–venue pair, with the 30-minute limit applied.
  5. Change monitoring. Re-check official pages on a schedule and flag any value that changed.
