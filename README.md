# Poker3 — Las Vegas Strip Poker Tournament Planner

**Goal:** Collect, organize, and analyze live upcoming poker tournaments near the Las Vegas Strip; find the best tournaments by cost to enter vs prize pool (single entry focus); keep re-entry/double-buy-in/add-on tournaments in a separate section; find hotels within a 30-minute walk with true per-night cost (room + resort fee + tax + parking); build an all-day playing schedule; publish a GitHub Pages site.

**Research date:** 2026-11-16 UTC

## Verification policy
Every table row links to an official verified source. If a value can't be confirmed from an official source, it is left blank and flagged — nothing is inferred or filled in. Hotel room rates and several fee figures are dynamic/not confirmed from official sources and are flagged accordingly.
