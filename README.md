# Vegas Poker Trip Planner

Source-first static dashboard for evaluating Las Vegas tournament schedules and lodging. Start at [Overview](index.html); the site includes tournaments, hotels, decision questions/suggestions, and a Flagged for review register.

**Data policy:** only official venue/hotel pages substantiate findings. Unknown values remain blank, events are not called single-entry unless official terms confirm it, and schedule information is not treated as a booking guarantee. Research snapshot: 2026-11-16 UTC. See [COORDINATION.md](COORDINATION.md) for provenance and verification notes.

GitHub Pages workflow is configured to deploy the root site on pushes to `main`; repository Pages settings must permit GitHub Actions.
