# All-Day Single-Entry Tournament Schedule — Las Vegas Strip

**Research date:** 2026-11-16
**Goal:** Enter as many live single-entry tournaments as possible on a planned vacation, playing all day.
**Constraint:** Single entry tournaments only (no re-entry/rebuy/add-on). One tournament at a time — you cannot be registered in two overlapping events.

## ⚠️ 8 AM start — not available
No tournament in any of the live Strip series reviewed starts at 8:00 AM.
- Earliest Venetian DSE IV start: 10:10 AM (events #3, #4, #5 RaceDay; #24 Seniors; #27 BIG O; #35 Tag Team; #39 LIPS Ladies; #47/$2,200; #52 PKO; #54/$600 bounty; #59/$600; #63/$600)
- WPT World Championship events start at 11:00 AM
- ARIA daily tournaments start at 1:00 PM
**Implication:** An "8 AM start" is not possible with current published schedules. The first playable single-entry event each day begins at 10:10 AM. This gap is flagged in COORDINATION.md and the Flagged for Review page.

## How to read this schedule
- "Primary" = the single-entry event to register for that day.
- "If busted early" = a later-starting single-entry event you can still enter if you lose your stack in the primary event (different events, so no single-entry conflict — you only lose one buy-in total per event).
- Day 2 restarts (multi-day events) are NOT listed as new entries; if you advance to Day 2 of a multi-day event, that day's play is committed.
- All events from Table A of data/tournaments.md; each row links to its official Venetian structure sheet.
